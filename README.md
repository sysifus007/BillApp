# BillApp -- 鸿蒙个人财务系统

> 基于 HarmonyOS 的个人收支管理应用

[![Language](https://img.shields.io/badge/Language-TypeScript-blue)]()
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## 项目简介

基于 HarmonyOS 开发的个人财务管理系统，帮助用户记录和管理日常收支，提供直观的数据统计和分析。

## 功能特性

| 功能 | 说明 |
|------|------|
| 收支记录 | 快速记录每笔收入和支出 |
| 分类管理 | 支持多种收支分类 (餐饮、交通、工资等) |
| 数据统计 | 按月/年查看收支趋势和分类占比 |
| 数据持久化 | 本地存储，数据不丢失 |

## 技术栈

| 技术 | 说明 |
|------|------|
| HarmonyOS | 华为自研操作系统 |
| ArkTS / TypeScript | 应用开发语言 |
| ArkUI | 声明式 UI 框架 |
| AppStorage | 应用级状态管理 |
